# FPS Performance Lab

An offline, browser-based student esports practice and performance-recording prototype.

## Run locally

Open `index.html` in a current Chromium-based browser. No installation, hosting account,
paid service, login, or server is needed. It has a precision-target exercise and
a GO/HOLD inhibition exercise. Use the controls in the app to start a session and
export the session's own JSON/CSV records.

## Reproducibility

This tree is a reviewed distribution candidate built from an already-tested offline ZIP.
The verified package was tested via automated Chromium to finish 20 precision targets,
execute 24 GO/HOLD cues, and export JSON/CSV without outgoing HTTP requests.
No official competition judging or independent human study is claimed.
